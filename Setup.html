🎓 Student Management System

A powerful desktop application to manage students, marks, attendance and reports.

⬇ Download Setup (.exe) 💻 View Source Code

🚀 Features

  • Student Management
  • Marks & Attendance
  • Dashboard with Charts
  • Topper System
  • PDF Report Generation
  • Login System (Admin/User)
  • Photo Upload

📦 Installation (Inno Setup)

This application is packaged using Inno Setup.

  1. Download the setup file
  2. Run the installer
  3. Choose installation location
  4. Click Install
  5. Launch application

Default Install Path:

C:\Users\User\AppData\Roaming\StudentManagementSystem

Data Storage Path:

C:\Users\Public\StudentManagementSystem

🧠 Technologies Used

  • Python (Flask)
  • SQLite
  • HTML / CSS / JS
  • Chart.js
  • PyInstaller
  • Inno Setup
